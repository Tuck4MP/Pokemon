# Tracker Nuzlocke - Pokémon Infinite Fusion

Site simples e interativo para:

- ver onde encontrar Pokémon no Infinite Fusion;
- marcar quais você já capturou;
- filtrar por rota/local;
- buscar por nome.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Marque os Pokémon capturados.
3. O progresso fica salvo no navegador (LocalStorage).

## Personalização

Edite o array `pokemonData` em `app.js` para adicionar/remover Pokémon e locais conforme suas regras de nuzlocke.
